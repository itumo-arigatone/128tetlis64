# 128tetlis64

Arduino（ATmega328P）+ SSD1306 OLED（128×64）で動くテトリス。

スケッチ: [`tetlis/tetlis.ino`](tetlis/tetlis.ino)

## 必要なもの

- ATmega328P ボード（Uno / Nano 相当）
- SSD1306 OLED 128×64（I2C・4線）
- ボタン × 6（十字 + A/B）
- （任意）LiPo + TP4056 + 5V 昇圧 + 100kΩ × 2（残量表示用）

ライブラリ（Arduino Library Manager）:

- Adafruit SSD1306
- Adafruit GFX Library

## 電源

想定構成:

```text
LiPo ── TP4056（充電）──┬── 昇圧モジュール ── 5V ── Arduino / OLED
                        │
                        └──（任意）分圧で残量計測 → A1
```

- MCU / OLED は昇圧後の **5V** で動かす
- 残量表示は昇圧後ではなく **LiPo セル電圧（TP4056 の B+）** を測る

USB だけで動かしてもゲーム自体は動く。バッテリー分圧が無い／不正なときは残量％は出ないだけ。

## 配線

### OLED（I2C）

| OLED | Arduino |
|------|---------|
| VCC | 5V（またはモジュール仕様どおり 3.3V） |
| GND | GND |
| SDA | A4 |
| SCL | A5 |

4線モジュール想定（RESET 線なし）。アドレスは `0x3C` / `0x3D` を自動検出。

### ボタン

押すと GND に落とす（`INPUT_PULLUP`）。各ボタンの一端をピン、もう一端を GND。

| ピン | ボタン | 動作 |
|------|--------|------|
| D2 | ← | 左移動 |
| D3 | → | 右移動 |
| D5 | ↑ | ハードドロップ |
| D6 | ↓ | ソフトドロップ |
| D7 | A | 右回転 |
| D8 | B | 左回転 |

D4 は未使用。D13 は動作確認用の内蔵 LED（ハートビート）。

### バッテリー残量（任意）

100kΩ を **2本** 使い、B+ と GND の間で分圧して真ん中を A1 へ。

```text
  TP4056 の B+（＝LiPo の +）
           │
         [100kΩ]     ← 1本目
           │
           ├────────→ Arduino A1
           │
         [100kΩ]     ← 2本目
           │
          GND  ←→ Arduino GND
```

- 満充電 4.2V のとき A1 は約 2.1V
- 画面右上に `NN%`（妥当な電圧のときだけ）
- 空〜満の目安: 3.3V → 0%、4.2V → 100%

## LED 診断

| 内蔵 LED (D13) | 意味 |
|----------------|------|
| 約 0.5 秒周期 | 正常動作 |
| 2 回点滅の繰り返し | OLED が I2C 上に見つからない |
| 3 回点滅の繰り返し | OLED `begin` 失敗 |

## 操作・画面

- 左: ライン数 / スコア
- 中央: フィールド（着地ゴーストあり）
- 右: ネクストミノ
- 右上: バッテリー残量（配線時のみ）
- ライン消去時: 消える行が短く点滅してから詰む
- ゲームオーバー: どれかボタンでリスタート（押しっぱなし即再開は防止）

## ゲーム座標メモ

- 開始位置は壁の頂点から2ブロック上とする
- 壁を合わせて6ブロック目を x 座標の 0 とみる
- 壁の頂点を y 座標の 0 とみる。下に行くほど数字は上がる
- 1 block は 2×2 px
